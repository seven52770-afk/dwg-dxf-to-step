# 接單與報價
先確認圖檔或尺寸、數量、材料、用途、精度、外觀、交期。未知成本和交期不可虛構。
使用「計算報價」工具，公式為：每件材料費=重量(g)/1000×材料單價(元/kg)；每件列印成本=(材料費+機時×機台時薪)×(1+耗損率)+後處理費。
總成本=每件列印成本×數量+一次性設計費+整筆包裝運費。未稅報價=總成本×(1+成本加成率)。成本加成率不是毛利率；本工具不計稅。
工具輸出的金額與算式優先，不要自行重算後改寫數字。試算非正式承諾。請使用者填入自己的成本。
回覆客戶時用短段落，可保留「交期待確認」。不能聲稱已送出訊息。
